Система скоринга монет портфеля

Обновлено: 01.08.2026  ·  RSI Portfolio →  |  CoinAlert →  |  Все скрипты →

Что это

Автоматическая система глубокого анализа криптовалют портфеля. Каждая монета получает скоринг от 0 до 60 по 12 осям и группу риска 1–5. Результат используется для принятия решений: продать / держать / докупать.

Реализована в двух вариантах: двухэтапный (Haiku → Sonnet) и одноэтапный (Sonnet с WebSearch). В обоих случаях основа — рыночные данные из бесплатных API + веб-поиск через Claude.

Варианты исследования

researcher.py основной
3 этапа:
1. API prefetch (CoinGecko + DeFiLlama) — бесплатно
2. Claude Haiku + WebSearch — сбор сырых данных (vesting, revenue, команда, новости). Кэш 14 дней.
3. Claude Sonnet — чистый анализ по всем данным, без веб-доступа

Время: ~7 мин  Кэш Haiku: 14 дней
researcher_sonnet.py альтернатива
2 этапа:
1. API prefetch (CoinGecko + DeFiLlama) — бесплатно
2. Claude Sonnet + WebSearch — сам ищет и анализирует в одном запросе

Плюс: Sonnet сам решает что искать, нет потери данных между моделями. Лучше для малоизвестных монет.
Минус: Дороже и медленнее (~8 мин)

12 осей скоринга (1–5 каждая, итого /60)

1
Технология / продукт
Архитектура, инновации, зрелость, аудиты безопасности
2
Токеномика / разлоки
Vesting schedule, давление разлоков, инфляция, burn
3
Доход / value capture
Наличие дохода, P/S, механизм влияния на токен
4
Команда / инвесторы
Бэкграунд основателей, раунды, лид-инвесторы
5
Экосистема / метрики
TVL, DAU/MAU, объём 30d, active addresses, тренд
6
Нарратив / тайминг
Горячий ли нарратив, позиция в цикле, ближайший катализатор
7
Ликвидность
Дневной объём, spread, slippage $10K/$100K, возможность выйти
8
Регуляторный риск
SEC, делистинги, страновые ограничения
9
Конкурентная позиция
Растёт / держит / теряет долю рынка vs конкуренты
10
Централизация
Доля инсайдеров, governance (мультисиг / DAO), key-man риск
11
Безопасность
Аудиты, история взломов, CertiK-скор, критические баги
12
PMF / Реальное применение
Решает ли реальную проблему лучше альтернатив, платящие пользователи

Что происходит после анализа

РезультатГде сохраняетсяЧто делается

Скоринг и группаscores.jsonИспользуется для сортировки в портфеле
Сырые данные Haikuresearch_raw/SYMBOL.jsonКэш 14 дней — не перезапрашивается
Группа рискаconfig.py → GROUPSАвтоматически обновляется если группа изменилась
TG-уведомлениеTelegramОтправляется с группой, скорингом, кратким комментарием
💡 Кэш: Сырые данные Haiku (vesting, revenue, команда) кэшируются на 14 дней в research_raw/. При повторном запуске Haiku не вызывается — только Sonnet переанализирует. Это экономит ~60% стоимости повторного research.
